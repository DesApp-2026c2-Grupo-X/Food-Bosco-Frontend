- Objetivo: publicar la corrección del login entre aplicaciones para que pueda revisarse e integrarse.
- Qué se hizo: se revisaron los cambios, se armó el commit, se subió la rama y se abrió el PR a develop.
- Puntos clave:

  - El servidor rechaza cuentas que no pertenecen a esa aplicación.
  - Cada app limpia la sesión si el rol no corresponde y avisa en el login.
  - Se actualizaron tests y documentación.
- Siguiente paso: revisar el PR y aprobarlo.
