# Cupones para vos y productos en promoción

- Fecha: 2026-11-19T08:05:00-03:00
- App: store
- Autor del prompt: usuario

## Prompt

> A las secciones existentes 'Inicio', 'Catalogo', Sucursal
>
> Promociones para vos que pase a llamarse Cupones para vos, y que si alguna promocion es sobre productos que vaya en una seccion 'productos en promocion'

## Informe

- Resumen: el usuario pidió renombrar la sección de promociones y separar las promociones de productos.
- Objetivo: distinguir cupones generales de productos con descuento.
- Qué se hizo: se renombró “Promociones para vos” a “Cupones para vos” y se agregó “Productos en promoción”.
- Puntos clave:
  - Las promociones por categoría o pedido quedan en Cupones.
  - Las promociones con productos afectados se muestran como tarjetas de producto.
  - Se deduplican productos si varias promociones apuntan al mismo.
  - No se modificaron las secciones de navegación Inicio, Catálogo y Sucursales.
  - Se agregó una promoción demo de sushi para ver la sección.
